# Ying Xu — Personal Website

Personal website built with [Astro](https://astro.build), deployed to GitHub Pages at [fibrecase.github.io](https://fibrecase.github.io).

## Commands

```sh
npm install     # install dependencies
npm run dev     # start local dev server at localhost:4321
npm run build   # build production site to ./dist/
```

Push to `main` to trigger the Pages deploy workflow.
